# BTR DEX

Adaptive multi-asset AMM with zkSNARK-based privacy layer.

## Project Structure

This repo = **Solidity contracts + Bun keepers only** (post Phase 30 split). Front/back/SDK live in sibling repos under `~/Work/btr/`:

| Concern | Repo |
|---|---|
| dApp UI | `~/Work/btr/front` (SvelteKit, `@btr-protocol/front`) |
| Off-chain services | `~/Work/btr/back` (Bun, `@btr-protocol/back`) |
| Shared TS types + ABIs + eth client | `~/Work/btr/sdk` (`@btr-protocol/sdk`) |
| Swap aggregator SDK | `~/Work/btr/swap` (`@btr-supply/swap`) |

Local layout:
- **evm/** - Solidity smart contracts (main implementation)
- **circuits/** - zkSNARK circuits for dark pool privacy
- **keeper/** - Off-chain guardian for circuit breakers and oracle updates
- **sim/** - Simulation harness
- **specs/** - Canonical technical specifications
- **dumps/** - Code export outputs (generated by `./dump` script)

## Developer Tools

### Code Export Utility

The `./dump` script exports code to timestamped text files for LLM consumption.

```bash
# Export AIMM contracts only
./dump --aimm

# Export dark pool contracts (excludes generated files)
./dump --darkpool

# Export circuits
./dump --circuits

# Export multiple components
./dump --aimm --darkpool --circuits
```

See [README_DUMP.md](README_DUMP.md) for details.
