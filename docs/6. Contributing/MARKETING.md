## 2. Brand Voice & Messaging

### Voice Characteristics

| Trait | Description | Example |
|-------|-------------|---------|
| **Expert but accessible** | DeFi made simple | "Capital efficiency for everyone" |
| **Transparent** | Honest about risks | "APY fluctuates with market conditions" |
| **Innovative** | Forward-thinking | "Redefining liquidity provision" |
| **Community-first** | User-focused | "Built by traders, for traders" |

### Key Messages

1. **Single-sided LP**: Deposit one token, not pairs
2. **Capital efficiency**: Higher returns per dollar
3. **Multi-asset**: Trade any-to-any through anchor tree
4. **Cooperative arbitrage**: Profits return to LPs
5. **Security first**: Audited, battle-tested

### Messaging Do's and Don'ts

| Do | Don't |
|-----|-------|
| "Earn passive income" | "Guaranteed returns" |
| "Historical APY: 15%" | "You will earn 15%" |
| "Advanced risk management" | "Risk-free" |
| "Competitive fees" | "Lowest fees" (without proof) |

## 4. Social Media Strategy

### Platform-Specific Tactics

**Twitter/X:**
- 3-5 tweets daily
- Mix: educational, engagement, updates
- Use threads for complex topics
- Engage with replies within 1 hour
- Relevant hashtags: #DeFi #AMM #Liquidity

**Discord:**
- Daily community check-ins
- Weekly AMA with team
- Bug bounty announcements
- Governance discussions
- Support response <4 hours

**Telegram:**
- Major announcements only
- Price discussion discouraged
- Link to Discord for discussion

**Medium/LinkedIn:**
- Technical deep-dives
- Partnership announcements
- Thought leadership
- Cross-post to Twitter

### Content Amplification

| Tactic | Description |
|--------|-------------|
| **KOL partnerships** | Collaborate with DeFi influencers |
| **Community takeover** | Invite guests to host spaces |
| **Cross-promotion** | Partner with integrated protocols |
| **Press releases** | Milestone announcements via crypto media |

## 5. Community Building

### Community Roles

| Role | Responsibilities | Requirements |
|------|------------------|--------------|
| **Moderator** | Keep discussions healthy, answer questions | Active, trusted |
| **Ambassador** | Create content, organize events | Passionate, knowledgeable |
| **Contributor** | Code, docs, translations | Skill-based |
| **Whale** | Large LP, provides liquidity | Capital commitment |

### Engagement Activities

| Activity | Frequency | Goal |
|----------|-----------|------|
| **AMA Session** | Bi-weekly | Transparency, feedback |
| **Trading Competition** | Quarterly | Volume, awareness |
| **Bug Bounty** | Ongoing | Security, engagement |
| **Governance Vote** | Per proposal | Decentralization |
| **Merch Store** | Launch | Brand loyalty |

### Onboarding Flow

1. **Welcome message** with key links
2. **Quick start guide** for new users
3. **Assign role** based on interest (trader, LP, dev)
4. **Invite to testnet** for hands-on experience
5. **Schedule 1:1** for whales/partners

## 6. Growth Tactics

### Partnership Framework

| Partner Type | Value Proposition | Outreach |
|--------------|------------------|----------|
| **Other DEXs** | Liquidity aggregation | Shared fees |
| **Wallets** | Default integration | User acquisition |
| **Oracles** | Data partnership | Improved pricing |
| **Yield aggregators** | Route to AIMM pools | Volume |
| **Influencers** | Content creation | Affiliate links |

### Referral Program

```
Tier 1 (0-10 referrals):   5% of trading fees
Tier 2 (10-50 referrals):  10% of trading fees
Tier 3 (50+ referrals):    15% of trading fees + whitelist
```

### Airdrop Strategy

1. **Snapshot** at key milestones
2. **Qualification**: LPs, traders, governance voters
3. **Vesting**: 6-month cliff, linear vesting
4. **Claim**: Via governance vote

## 10. Campaign Examples

### Launch Campaign

**Phase 1: Pre-launch (2 weeks)**
- Teasers on Twitter
- Whitelist opening
- Testnet faucet

**Phase 2: Launch (1 week)**
- Announce mainnet
- Trading competition ($10K prizes)
- Initial LP incentives

**Phase 3: Post-launch (4 weeks)**
- Weekly updates
- KOL partnerships
- Research publication

### Ongoing Campaigns

|----------|------|----------|
| **LP Incentive** | Attract liquidity | Ongoing |

## 11. Common Pitfalls

| Pitfall | Solution |
|---------|----------|
| Overpromising on returns | Use historical ranges, disclaimers |
| Ignoring community feedback | Regular surveys, AMAs |
| Inconsistent posting | Content calendar, scheduling tools |
| Focusing only on price | Emphasize product, technology |
| Neglecting risk communication | Transparent risk disclosures |
